# ghGallery

**ghGallery** は、**Tauri・React・TypeScript** を使用して開発された、高速で多機能なデスクトップ向けメディアギャラリーです。

ローカルに保存されている画像や動画を快適に閲覧できるよう設計されており、自動グループ化、お気に入り、検索、ブックマーク、多言語対応などの機能を備えています。

---

## ✨ 主な機能

* **🚀 Tauri v2 デスクトップアプリ**

  * Tauri v2 を採用した軽量かつ高性能なネイティブデスクトップアプリです。

* **📂 フォルダ・ファイル管理**

  * サイドバーのブックマークから、ローカルのフォルダや個々のメディアファイルを簡単に開けます。

* **📦 自動グループ化**

  * 連番ファイルなど、関連性のあるファイルを自動的にグループ化します。
  * カスタム設定によって、自動グループ化の動作を上書きすることもできます。

* **⭐ お気に入り・検索**

  * お気に入りに登録した項目だけをすばやく絞り込めます。
  * ファイル名をリアルタイムで検索できます。

* **🎬 統合メディアビューア**

  * 画像の閲覧や動画の再生に対応しています。
  * 動画再生には **Plyr** を使用しています。

* **🌐 多言語対応**

  * **日本語・英語**の2言語に対応しています。
  * アプリ内から言語をシームレスに切り替えられます。

# English

**ghGallery** is a fast and feature-rich desktop media gallery built with **Tauri, React, and TypeScript**.

It is designed for smooth browsing of local images and videos, with features such as automatic grouping, favorites, search, bookmarks, and multilingual support.

---

## ✨ Features

* **🚀 Tauri v2 Desktop App**

  * A lightweight and high-performance native desktop application powered by Tauri v2.

* **📂 Folder & File Management**

  * Easily open local folders and individual media files using bookmarks in the sidebar.

* **📦 Automatic Grouping**

  * Automatically groups related files, such as numbered or sequential files.
  * Custom settings can be used to override the automatic grouping behavior.

* **⭐ Favorites & Search**

  * Quickly filter your media using favorites.
  * Search file names in real time.

* **🎬 Integrated Media Viewer**

  * Browse images and play videos directly within the application.
  * Video playback is powered by **Plyr**.

* **🌐 Multilingual Support**

  * Supports **Japanese and English**.
  * You can switch between languages from the application settings.
